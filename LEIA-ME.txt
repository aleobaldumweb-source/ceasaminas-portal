IMPLEMENTAÇÃO — NOTÍCIAS OFICIAIS DA CEASAMINAS COM IMAGENS

Execute tudo na raiz:
C:\Users\baldoino\Desktop\projetos\ceasaminas-portal

1) Instale os campos e atualize API/DTO:
   Set-ExecutionPolicy -Scope Process Bypass
   .\01-instalar-campos-noticias.ps1

2) Formate e valide o schema:
   pnpm --filter @ceasaminas/database exec prisma format --schema prisma/schema.prisma
   pnpm --filter @ceasaminas/database exec prisma validate --config prisma.config.ts

3) Crie a migração:
   pnpm --filter @ceasaminas/database exec prisma migrate dev --name add-news-image-and-source --config prisma.config.ts

4) Gere o Prisma Client:
   pnpm db:generate

5) Compile a API:
   pnpm --filter @ceasaminas/api build

6) Importe as notícias e imagens oficiais:
   .\02-importar-noticias-oficiais.ps1

7) Inicie novamente:
   Terminal da API:
   pnpm --filter @ceasaminas/api dev

   Terminal do Admin:
   pnpm --filter @ceasaminas/admin dev

Observações:
- O importador somente aceita imagens encontradas nas páginas oficiais.
- Ele interrompe a operação se não localizar uma imagem oficial, evitando imagem incorreta.
- A importação é idempotente: executar novamente atualiza as mesmas notícias pelo slug.
- Os textos armazenados são resumos editoriais e mantêm sourceUrl para consulta do conteúdo integral.
